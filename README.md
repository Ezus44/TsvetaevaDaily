# Стихи Дня

Android-приложение: каждый день показывает одно стихотворение — Марины Цветаевой, Софии Парнок,
Александра Пушкина, Владимира Маяковского или Александра Блока — из всех, что опубликованы
в Викитеке (ru.wikisource.org).

## Авторы

Вверху — вкладки: **Цветаева, Парнок, Пушкин, Маяковский, Блок**. Переключаться можно касанием
или свайпом; у каждого автора свой стих дня и своя история «недавно показанных».
Стихи каждого автора скачиваются **только по выбору**: на вкладке незагруженного автора есть кнопка
«Загрузить» (один раз, несколько минут; у Пушкина — дольше всех). Загрузку можно отменить.
В Настройках → «Загруженные авторы» видно, кто уже на телефоне, и там же можно загрузить,
обновить или удалить стихи любого автора. Загрузки идут по очереди, чтобы не перегружать Викитеку.

**Основной автор** (Настройки → «Основной автор», отмечен звёздочкой на вкладке) открывается
при запуске, и его стих приходит в ежедневном уведомлении (если его стихи загружены). По умолчанию — Цветаева.

## Оформление

У каждого поэта своя вкладка-«бумага»: палитра (светлая и тёмная — по системной теме) и шрифт.
При свайпе видно, как одна страница сменяет другую, а рамка (дата, вкладки, настройки) плавно
перекрашивается под выбранного поэта. Имя на вкладке набрано шрифтом самого поэта.

| Поэт | Палитра | Шрифт | Почему |
|---|---|---|---|
| Цветаева | рябиновый красный на тёплой бумаге | Cormorant Garamond | Рябина — её сквозной образ («Красною кистью рябина зажглась…»). Острая, контрастная антиква — под её тире, обрывы строки и напор. |
| Парнок | винно-сливовый на светлом камне, мягкий контраст | Alegreya | Её книги — «Розы Пиерии», «Лоза», «Вполголоса»: античность, Сапфо, вино; тихий голос. У Alegreya каллиграфический, «рукописный» ритм — интимно, без нажима. |
| Пушкин | бурые чернила на пожелтевшей бумаге, золото | Old Standard TT | Рукописи пером орешковыми чернилами и «золотой век». Old Standard воспроизводит книжный шрифт русских изданий XIX века. |
| Маяковский | красное и чёрное на газетной бумаге | Oswald | «Окна РОСТА» и рекламные плакаты с Родченко. Узкий рубленый гротеск, заглавия заглавными буквами, прямоугольные плашки без скруглений, подписи без курсива. |
| Блок | днём — сумеречная синева и туман белой ночи; ночью — свет фонаря на тёмно-синем | Playfair Display | Символизм: «Ты в синий плащ печально завернулась», «Ночь, улица, фонарь, аптека». Контрастная антиква с волосяными линиями, заглавия курсивом. |

Контраст основного текста во всех палитрах — от 12.7:1, подписей и акцентов — не ниже 4.9:1 (WCAG AA).
Шрифты — Google Fonts под лицензией SIL Open Font License, тексты лицензий — в `fonts-licenses/`.

## Как выбирается стихотворение

1. Если есть стихи, написанные **в этот же день** (число и месяц совпадают с сегодняшним) —
   случайное из них. На экране будет пометка «Написано в этот же день, в 1915 году».
2. Иначе — случайное из пяти ближайших по дате (в пределах двух недель).
3. Если рядом с сегодняшним числом дат нет — совсем случайное.

Недавно показанные стихи не повторяются. Стих дня один на весь день; кнопка «Другое» меняет его.
В настройках можно переключиться на «совсем случайно».

## Откуда берутся стихи

По кнопке «Загрузить» приложение обходит Викитеку через API Викимедиа
(ниже — на примере Цветаевой; для остальных авторов так же, от их страниц и категорий):
оглавления «Стихотворения 1906—1920 (Цветаева)», «Стихотворения 1921—1941 (Цветаева)»,
страницу автора и его категории → все страницы с пометкой «(Цветаева)» → сборники и циклы
→ отдельные стихи. Тексты, вычитанные по сканам, берутся из готового HTML.
Даты написания извлекаются из подписей под стихами («Москва, 6 октября 1915», «11 XII 1918»)
и из оглавлений (годом считается только год из жизни автора). Проза, примечания, варианты
и чужие эпиграфы отсекаются.

Стихи на Викитеке размечены по-разному, приложение понимает основные варианты: блоки `<poem>`,
шаблоны `{{poemx|заглавие|текст|дата}}`, `{{f1}}`, `{{f2}}`, `{{v}}`, «лесенку» Маяковского
(`{{лесенка}}`), стихи без `<poem>` после `{{poem-on}}` и сборники Парнок из az.lib.ru
(таблицы со строками через `<br>`).
Если текст лежит в нескольких изданиях — например, у Пушкина в современной и дореформенной
орфографии, — остаётся один вариант, в современной орфографии.

Это занимает 1–3 минуты, дальше всё работает без интернета.
Раз в неделю загруженные авторы тихо обновляются по Wi‑Fi
(или вручную: Настройки → «Загруженные авторы» → «Обновить»).

## Уведомление

Каждый день (по умолчанию в 9:00, время меняется в настройках) приходит уведомление
со стихом дня основного автора; нажатие открывает приложение.

## Как получить APK

**Вариант 1 — GitHub (без установки чего-либо):**
1. Создайте пустой репозиторий на github.com и загрузите в него эту папку
   (`git init && git add . && git commit -m init && git remote add origin … && git push -u origin main`,
   или через кнопку «uploading an existing file»).
2. Вкладка **Actions** → сборка «Сборка APK» запустится сама (≈5 минут).
3. Откройте завершённую сборку → внизу **Artifacts** → `stikhi-dnya-apk` → скачайте,
   распакуйте и установите `stikhi-dnya.apk` на телефон
   (разрешите установку из неизвестных источников).

**Вариант 2 — Android Studio:** File → Open → папка проекта → Run ▶ (или Build → Build APK).

Требования: Android 8.0+.

## Устройство проекта

```
app/src/main/java/ru/tsvetaeva/daily/
  core/          чистая логика без Android (покрыта тестами)
    Author       авторы: вкладки, страницы и категории Викитеки, годы жизни
    WikiParser   разбор викитекста: блоки <poem>, заголовки, подписи с датами, ссылки
    HtmlToWiki   HTML страниц из сканов → викитекст
    Dates        распознавание дат («6 октября 1915», «1-го мая», «11 XII 1918»)
    PoemPicker   выбор стиха дня
    Dedupe       один текст в разных изданиях и орфографиях → одно стихотворение
  data/
    WikiApi      клиент MediaWiki API ru.wikisource.org
    PoemRepository  обход Викитеки, офлайн-база, стих дня (по одной на автора)
  notify/        ежедневное уведомление и еженедельное обновление (WorkManager)
  ui/Theme       оформление каждого поэта: палитры, шрифты
  MainActivity   интерфейс (Jetpack Compose)
app/src/test/    тесты логики: ./gradlew testDebugUnitTest
```

APK подписывается ключом `app/sideload.keystore` — он нужен только для установки вручную,
чтобы новые сборки ставились поверх старых. Для публикации в Google Play замените его своим.

Тексты Цветаевой, Парнок, Пушкина, Маяковского и Блока — общественное достояние; источник — Викитека.
Идентификатор приложения (`ru.tsvetaeva.daily`) оставлен прежним, чтобы новые версии ставились поверх старых.
